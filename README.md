# Age Calculator (Python Tkinter)

A desktop application built using Python and Tkinter that calculates a user's exact age in years based on their date of birth.

## Features
- **Graphical User Interface:** Built with Tkinter entry fields, buttons, and custom image branding.
- **Accurate Calculation:** Computes precise age using Python's `datetime` module.
- **Dynamic Feedback:** Validates and displays the results cleanly.

## Technologies Used
- Python 3
- Tkinter (GUI Framework)
- Pillow (PIL) for image handling
